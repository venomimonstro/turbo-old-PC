# Windows EXE: скачать и запустить

**Исполняемые файлы подготовлены для Windows 10/11 x64.** Это предварительные кросс-собранные исполняемые пакеты; запуск на Windows пока не подтверждён. Подписи Authenticode нет, поэтому Windows SmartScreen или другой установленный антивирус может показать предупреждение. Не отключайте защиту ради установки.

- **Установщик:** [TurboOldPC-0.4.0-Setup.exe](https://github.com/venomimonstro/turbo-old-PC/raw/refs/heads/main/dist/TurboOldPC-0.4.0-Setup.exe) — один EXE, распаковывает компоненты во временную директорию, запрашивает согласие, запускает пользовательский установщик и создаёт обычный EXE запуска.
- **Портативная версия:** [TurboOldPC-0.4.0-Portable.exe](https://github.com/venomimonstro/turbo-old-PC/raw/refs/heads/main/dist/TurboOldPC-0.4.0-Portable.exe) — один EXE, распаковывает компоненты во временный каталог и запускает окно программы. Установка не нужна.

Оба EXE содержат один и тот же снимок исходников, работоспособность которых ещё необходимо проверить на настоящих Windows 10/11. Используется встроенный в Windows PowerShell 5.1, но пользователь не должен запускать скрипты вручную. Поддержка 32-битных Windows в этих EXE отсутствует. Программу нельзя считать промышленным антивирусом: основной движок — Microsoft Defender, собственный сканер экспериментален.

# Turbo Old PC 0.4.0 — безопасность, драйверы, ускорение с откатом

**Бесплатная портативная программа для обслуживания слабых компьютеров на Windows 10 и Windows 11.**

Интерфейс на русском, крупные кнопки и навигация слева, как в привычных программах обслуживания ПК. Turbo Old PC помогает находить причины торможения, запускать встроенный антивирус Windows, удалять старые временные файлы и разбираться с автозагрузкой и драйверами. Никакой рекламы, подписки, регистрации или передачи данных на наши серверы.

**Версия: 0.4.0 (предварительная).** Требует испытаний на реальных Windows 10/11 перед массовым распространением. Не заявляем, что ПК станет быстрее на фиксированный процент.

## EXE: обычная установка и портативная программа

В исходниках подготовлена локальная сборка трёх исполняемых файлов Windows из одного ZIP с одинаковыми модулями:

- **TurboOldPC-0.4.0-Setup.exe** — запускает пользовательский установщик без прав администратора, устанавливает программу в `%LOCALAPPDATA%\Programs\TurboOldPC`, добавляет обычный `TurboOldPC.exe` и ярлыки.
- **TurboOldPC-0.4.0-Portable.exe** — сам распаковывает встроенные компоненты во временную папку, запускает окно и пытается удалить временные файлы после закрытия. Постоянную установку не создаёт; диагностические отчёты и журналы настроек сохраняются в профиле пользователя.
- **TurboOldPC.exe** — установленный графический запускатель, который открывает программу из `app\TurboOldPC.ps1`.

Сборка на Windows 10/11 выполняется штатным компилятором .NET Framework и PowerShell 5.1 (без GitHub Actions):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-WindowsExe.ps1 -Version 0.4.0
```

Перед упаковкой выполняются smoke-тесты; при ошибке сборка должна остановиться. **Бинарники ещё не скомпилированы и не проверены в этой среде**; исполняемые `.exe` в `dist` опубликованы, но не испытаны на Windows. Для распространения необходимы реальная сборка и испытания на Windows, проверка установщика/удаления, контроль SHA-256 и подписание исполняемых файлов доверенным сертификатом. Без этого нельзя считать релиз пригодным для массовой установки.

## Скачать

- **Актуальный исходный код (не готовые EXE):** скачайте репозиторий через **Code → Download ZIP**. Архив в папке `dist` от предыдущей версии устарел. Для сборки отдельного portable ZIP запустите `tools/Build-Portable.ps1` локально на Windows.
- Альтернатива: **Code → Download ZIP** на странице GitHub.

### Портативный запуск — без установки

1. Скачайте архив, проверьте источник, распакуйте **всю** папку.
2. Двойной щелчок по **Turbo Old PC.vbs** открывает графическое окно без консоли.
3. Если Windows Script Host отключён администратором, запускайте **Start.cmd**.
4. После открытия программа сама проведёт первую диагностику. Для очистки и полной проверки потребуется отдельное подтверждение.

Для обычной диагностики права администратора не требуются. Скрипты PowerShell не подписаны сертификатом разработчика, поэтому Windows или антивирус могут запросить дополнительное подтверждение. Никогда не обходите предупреждение безопасности для архива из неизвестного источника. Репозиторий открыт для аудита.

### Установка одним двойным щелчком

1. Распакуйте ZIP.
2. Запустите **Install.cmd**.
3. Программа будет установлена **только для текущего пользователя** в `%LOCALAPPDATA%\Programs\TurboOldPC`.
4. Создаются ярлыки на рабочем столе и в меню «Пуск». В «Установленных приложениях» появляется запись для удаления.

**Удаление:** Параметры Windows → Приложения → Установленные приложения → Turbo Old PC → Удалить. Локальные диагностические отчёты сохраняются, системные службы и драйверы не затрагиваются. Для переустановки просто ещё раз запустите `Install.cmd` из новой распакованной версии, предварительно закрыв приложение.

## Почему старый ПК работает медленно

В первую очередь проверяйте следующее:

1. **Дисковая нагрузка.** Проверьте процессы, автозагрузку, ошибки накопителя и свободное место; очистка временных файлов не лечит неисправный диск.
2. **Нехватка памяти.** Сократите количество фоновых приложений, вкладок браузера и необязательных программ в автозагрузке.
3. **Неисправный диск или перегрев.** Программная оптимизация это не исправит. При подозрении на неисправный диск **сначала сохраните данные**.
4. **Перегрузка автозагрузки и фоновых приложений.** Отключайте только заведомо необязательные элементы, не трогая антивирус, драйверы и службы безопасности.
5. **Вредоносное ПО и отсутствие обновлений.** Используйте встроенную защиту и поддерживаемую версию Windows.

Windows 10 закончила стандартную поддержку 14 октября 2025 года. Изучите возможность перехода на поддерживаемую ОС или участие в программе Extended Security Updates: [информация Microsoft](https://support.microsoft.com/en-us/windows/deployment/updates-lifecycle/windows-10-support-has-ended-on-october-14-2025).

## Ограничения и честная безопасность

- Антивирусный движок **не разработан нами**: сканирование выполняет Microsoft Defender. Если активен другой антивирус, пользуйтесь им.
- **Драйверы можно устанавливать по одному** из обновлений, найденных Windows Update Agent. Инсталляция требует UAC и созданной новой точки восстановления; в противном случае запрещена. **Автоматическое скачивание с сайтов OEM не реализовано**; произвольные драйвер-паки запрещены.
- Программа **не удаляет приложения по эвристике**, не выключает службы Windows, Defender и обновления, не редактирует реестр для ускорения. Запись реестра HKCU при установке нужна только для стандартного удаления самой программы.
- Показатель HealthStatus диска — приблизительная оценка, а не полноценный SMART-тест или гарантия исправности. При сомнениях используйте специальную диагностику накопителя и резервное копирование.
- Данные не отправляются автоматически никуда. Отчёты сохраняются в `%LOCALAPPDATA%\TurboOldPC\Reports`. Они могут содержать список программ, пути и идентификаторы устройств — не публикуйте их без проверки.
- Удаление Temp необратимо, но касается только указанного каталога и старых файлов. Перед любым серьёзным обслуживанием полезна резервная копия важных файлов.

## Разработчикам

- `Turbo Old PC.vbs` — тихий портативный запуск; `Start.cmd` — запуск с консолью для поиска ошибок.
- `Install.cmd` и `install/Install.ps1` — установка без прав администратора.
- `install/Uninstall.ps1` — удаление установленной копии, не затрагивает пользовательские отчёты.
- `app/TurboOldPC.ps1` — WPF-интерфейс Windows PowerShell 5.1.
- `app/Turbo.Core.psm1` — сбор сведений и изолированная очистка.
- `app/Workers` — фоновые задания диагностики, очистки и Defender.
- `tests/SmokeTest.ps1` — синтаксические, XML и файловые тесты.
- `app/Turbo.Security.psm1` — read-only аудит конфигурации безопасности.
- `app/Workers/DriverUpdates.ps1` — Windows Update Agent: поиск, выбор и установка драйвера.
- `app/Workers/Boost.ps1` — журналируемые настройки и откат.

Проверка на Windows: `powershell.exe -NoProfile -File .\tests\SmokeTest.ps1 -FullDiagnostics`. Команды теста очистки используют отдельную временную песочницу, а не пользовательский каталог Temp.

Проект намеренно **без GitHub Actions / CI**, изменения отправляются в `main`. Для массового распространения нужны реальные испытания на Windows 10 и 11, цифровая подпись поставки и проверка репутации установочного пакета. GitHub-хранилище и статические проверки **не заменяют** испытаний работающего интерфейса на Windows.

## Новое в 0.4.0 (исходная версия, требует Windows-испытаний)

**Глубокая очистка выбранного диска**: вкладка «Очистка» → «Глубокий анализ диска», затем укажите букву тома. Поиск идёт по нескольким ограниченным категориям: старые временные файлы пользователя и Windows, отчёты об ошибках и их очереди. Показывается объём по категориям; очистка запускается отдельно и требует подтверждения. Перед удалением перепроверяются возраст, размер, корень пути, отсутствие ссылок и принадлежность к разрешённой категории. Скрытые системные папки, чужие профили, загрузки, содержимое документов, кэш браузера с сеансами и бэкапы автоматически не удаляются. Размер освобождения может быть нулевым — обещание «гигабайтов» без подтверждённого анализа некорректно.

**Ремонт Windows**: новая вкладка «Починка Windows» с DISM ScanHealth, DISM RestoreHealth и SFC /scannow. Команды штатные, запускаются по отдельному согласию и с UAC. Перед изменяющими операциями необходима новая подтверждённая точка восстановления (при ошибке команда отменяется). Журнал создаётся локально. Это не полный откат файловой системы.

**Реестр**: только аудит записей Run текущего пользователя и машины, включая подозрительные ссылки на отсутствующие исполняемые файлы. Записи не удаляются автоматически: массовая очистка реестра мало помогает производительности и способна повредить загрузку приложений.

**Обновление поставки**: локальный скрипт `tools/Build-Portable.ps1` включает новые рабочие файлы. Команда `powershell.exe -NoProfile -File .\tools\Build-Portable.ps1 -Version 0.4.0`. Готовая сборка 0.4 пока **не проверена на реальном Windows-ноутбуке**.

См. [AUDIT.md](AUDIT.md) для открытых блокеров готовности.

**Карта занятого места:** кнопка «Куда ушло место?» анализирует выбранный диск, показывает крупнейшие каталоги верхнего уровня и файлы от 100 МБ, включая скрытые. Это только чтение: файлы не удаляются. Обход ограничен 180 000 файлов и 24 уровнями вложенности, поэтому при превышении лимита отчёт неполный.

## Движок антивируса и драйверы — последнее обновление исходников

- **Базы вирусов:** приложение не поставляет неизвестную статическую базу и не отключает защиту Windows. Оно использует официальный Microsoft Defender и его **регулярно обновляемые подписи и движок**. В разделе «Антивирус» доступны «Обновить базу вирусов», «Обнаружения» и «Обработать активные угрозы» (последнее требует отдельного согласия и UAC). История обнаружений не равна списку активных заражений. Для удаления используется штатный `Remove-MpThreat`, который действует на все активные угрозы, обнаруженные Defender. Это не самостоятельный антивирусный движок; нулевой день и целевые атаки не гарантированно обнаруживаются.
- **Инвентаризация драйверов:** кнопка «Установленные драйверы» показывает установленные PnP-пакеты, версии, производителей, INF и цифровую подпись. «Найти драйверы» — поиск доступных обновлений Windows Update Agent. «Установить выбранный» — индивидуальная установка через Windows Update после создания новой точки восстановления и UAC. Каталоги OEM не поддерживают единого безопасного API; автоматическую установку произвольных скачанных OEM EXE не заявляем.
- **Релиз:** собранные и подписанные `.exe` ещё отсутствуют в GitHub. Исходники содержат сценарии компиляции, но успешно работающий продукт можно заявить только после тестов Windows. Не используйте предварительную версию как единственную защиту ПК.

- Антивирус: официальные обновления сигнатур Defender, просмотр истории обнаружений и отдельно подтверждаемая обработка активных угроз.
- Драйверы: инвентаризация PnP-драйверов с версиями и подписями; отдельная установка предложенных Windows Update драйверов после новой точки восстановления.

- Установка: исходники `tools/Bootstrap.cs` и `tools/Build-WindowsExe.ps1` позволяют на Windows собрать установочный, портативный и установленный EXE. Добавлена проверка `tests/ReleaseGate.ps1`: заголовки PE/ZIP, обязательные модули, SHA-256, статус Authenticode. Режим `-RequireSignature` не пропускает неподписанные сборки.

**Приёмка:** текущая ветка содержит исходники и статические проверки. Без реальных EXE, проверки подписи, интеграционных тестов Windows 10/11 и исправления выявленных на них ошибок проект не является готовым выпуском. Ни одна антивирусная система не гарантирует обнаружение всех неизвестных угроз. Приложение не заменяет защиту Defender на уровне драйвера ядра.

## Собственный антивирусный модуль: текущее состояние

Добавлены `app/Turbo.Scanner.psm1` и `app/Workers/NativeScan.ps1` — собственное **дополнительное сигнатурное ядро** для сканирования выбранной папки. Оно рекурсивно перечисляет обычные файлы, пропускает reparse-point-ссылки, ограничивает их число и максимальный размер, вычисляет SHA-256 и сравнивает результат с локальным JSON-каталогом. Текущий каталог `data/signatures.json` содержит **только безвредную EICAR-тестовую сигнатуру**; реальные вирусные базы в программу ещё не включены. Сканер не имеет системного драйвера и не предотвращает атаки в реальном времени. Отсутствие совпадений с сигнатурой **не означает отсутствие вирусов**. Карантинный обработчик является экспериментальным и не доступен из интерфейса для произвольного использования.

Опционально есть **второй движок ClamAV** — кнопка «Вторая проверка ClamAV». Требует, чтобы пользователь отдельно установил официальный ClamAV для Windows, настроил и обновил базы через FreshClam. Компонент не скачивает неподтверждённые исполняемые файлы и не удаляет данные автоматически; результат записывается в журнал. Официальная документация: https://docs.clamav.net/manual/Installing.html, https://docs.clamav.net/manual/Usage/SignatureManagement.html. На старых компьютерах запуск нескольких сканирований подряд может значительно увеличивать нагрузку.

Текущая основная антивирусная защита Windows — **Microsoft Defender** с обновлением официальных сигнатур, историей угроз, карантином через «Безопасность Windows» и пользовательским запуском удаления обнаруженных активных угроз. Не отключайте его ради ускорения.

**Не выполнено для промышленного релиза:** большая независимо валидированная база, регулярно подписываемые обновления, тестовые вредоносные наборы, оценка ложных срабатываний, резидентный компонент, защита от программ-вымогателей уровня ядра, интеграция нескольких движков и тестирование на реальных Windows 10/11. Финальные установщик/портативный EXE по-прежнему не скомпилированы и не подписаны в этом окружении.


## Стабильность: исправления последнего обновления

- **Транзакционная установка:** `install/Install.ps1` сначала собирает и разбирает все скрипты пакета во временном каталоге, затем заменяет установленный каталог с резервной копией прежней версии и откатом при ошибке. Сбой удаления старого бэкапа не удаляет уже установленную новую версию.
- **Безопасное удаление:** `install/Uninstall.ps1` запрещает обход junction/symlink, не трогает чужие ярлыки и регистрационные записи, сохраняет пользовательские отчёты и историю изменений.
- **Удобный EXE-установщик:** диалог согласия с каталогом установки и предложение запустить программу после установки.
- **Отмена без риска:** можно прервать длительные операции чтения/анализа; завершение приложения блокируется при системных операциях, чтобы не оставить неполностью выполненное восстановление.
- **Диск:** добавлен переход в штатный мастер `cleanmgr.exe`, который позволяет выбирать категории системной очистки Windows. Самостоятельная глубокая очистка ограничивает размер списка кандидатов, чтобы не расходовать чрезмерно оперативную память.
- **Антивирус:** собственный сигнатурный сканер ограничен по времени, объёму хешируемых файлов и количеству объектов, явно показывает неполный анализ и ошибки чтения. **Экспериментальный собственный карантин удалён** как не прошедший аудит безопасности — изоляция и устранение угроз выполняются штатными средствами Microsoft Defender. Опциональный ClamAV получает официальные сигнатуры через установленный FreshClam (понадобятся права администратора).
- **Драйверы:** установка через Windows Update учитывает как общий результат операции, так и результат конкретного драйвера; частичная успешность не считается полным успехом.
- **Релиз:** `tests/SmokeTest.ps1` дополнен запуском реального WPF-интерфейса в скрытом режиме `-SmokeUi`, проверкой комплектности установщика и синтетической безопасной проверкой/очисткой. `tests/ReleaseGate.ps1` проверяет хеши критических файлов внутри ZIP против текущего исходного дерева.
- **Подпись:** `tools/Build-WindowsExe.ps1` имеет отдельный `-Release` режим, требующий сертификат с закрытым ключом, SHA-256 Authenticode и HTTPS timestamp. Без него сборка маркируется предварительной.

Пример официальной сборки на Windows **при наличии действующего сертификата подписи кода**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-WindowsExe.ps1 -Version 0.4.0 -Release -CertificateThumbprint "СОРОК_ШЕСТНАДЦАТЕРИЧНЫХ_СИМВОЛОВ" -TimestampServer "https://ваш-сервер-меток-времени.example"
```

Это описание интерфейса сборки, **не готовый релиз**: реальную компиляцию, подпись и испытания на чистой Windows 10/11 нужно провести в Windows. В репозитории есть предварительные EXE для скачивания, и проект нельзя рекламировать как проверенный полнофункциональный антивирус.
