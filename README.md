# Turbo Old PC

Безопасная диагностика и обслуживание старых ноутбуков с Windows 10/11.

> **Статус:** первая рабочая версия (MVP), код требует проверки на реальных компьютерах перед массовым распространением. Не обещает ускорение в N раз.

## Запуск

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте его в обычную папку.
2. Запустите **Start.cmd** двойным щелчком. Windows PowerShell 5.1 уже входит в Windows 10/11, установка Python или .NET SDK не нужна.
3. Подтвердите действия очистки отдельно в программе. Для просмотра сведений о системе права администратора не обязательны.
4. Если Windows заблокировала загруженный архив, сначала проверьте происхождение файлов и код перед разрешением запуска. Программа не подписана цифровым сертификатом.

Запуск из консоли: `powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\app\TurboOldPC.ps1`

**Важно:** флаг ExecutionPolicy действует только для дочернего процесса и используется для запуска локального неподписанного скрипта; его наличие не делает чужой скрипт безопасным. Не загружайте этот проект из посторонних источников.

## Функции MVP

| Возможность | Поведение |
| --- | --- |
| Анализ оборудования | CPU, модель ноутбука, RAM, системный диск, тип носителя (если Windows его определила), свободное место, ОС |
| Анализ старта Windows | События 100 Diagnostics-Performance, длительность запуска и этапов, при наличии записей |
| Автозагрузка | Показывает элементы автозапуска; открывает системную страницу для ручного управления |
| Ресурсы и службы | Показывает процессы с большим потреблением RAM и автоматически запущенные службы для ручной оценки; службы не отключает |
| Драйверы | Показывает устройства с ошибками PnP и точную модель; переход к драйверам через Windows Update и официальный сайт производителя |
| Вредоносное ПО | Запускает **встроенный Microsoft Defender**, его обновление баз и быструю проверку; не подменяет собой антивирус |
| Очистка | Предпросмотр и отдельное подтверждение удаления старых файлов **только** из пользовательского `%LOCALAPPDATA%\Temp` |
| Отчёт | Текстовый файл с результатами; остаётся только на компьютере |
| Защита системы | Не отключает Defender, Windows Update, службы безопасности, не меняет реестр и не устанавливает драйвер-паки |

Все ресурсоёмкие операции стартуют в отдельном PowerShell-процессе, чтобы интерфейс оставался отзывчивым. Интернет для диагностики и очистки не требуется; обновление антивирусных баз и скачивание драйверов зависят от сети.

## Чего программа принципиально не делает

- Не обещает лечить физически изношенный HDD, перегрев или дефицит RAM.
- Не выключает массово службы и задачи Windows, не отключает защиту, UAC, обновления, файл подкачки и индексирование вслепую.
- Перечень сторонних служб — эвристический: отсутствие в списке не означает, что служба системная, а присутствие не означает, что её можно отключить.
- Не чистит системные каталоги, папки браузеров, пользовательские документы, загрузки или корзину.
- Не устанавливает драйверы со сторонних сайтов: совместимость и происхождение проверяются через Windows Update или OEM-сайт **самим пользователем**. Автоматическая проверка, скачивание и установка OEM-драйверов пока **не реализованы**.
- Не определяет заражение самостоятельно — использует статус и сканирование Microsoft Defender. При другом антивирусе предлагает пользоваться им.
- Не удаляет безвозвратно «подозрительные программы» по названию: ложноположительные срабатывания опасны.

## Как получить реальную скорость

1. Если системный диск — HDD, в первую очередь оценить его состояние и возможность установки SSD. При проблемах с диском — немедленно резервировать данные.
2. Если оперативной памяти 4 ГБ или меньше, проверить возможность установки 8 ГБ или более в пределах совместимости модели.
3. В Windows отключить ненужные элементы автозагрузки после проверки назначений.
4. Проверить компьютер Microsoft Defender, установить подходящие обновления Windows/драйверов.
5. Сравнить скорость загрузки **до и после** — первая загрузка после обновлений не репрезентативна.

Windows 10 прекратила стандартную поддержку **14 октября 2025 года**. Не стоит отключать защиту ради нескольких процентов скорости; проверьте поддерживаемые пути обновления ОС и программы расширенных обновлений безопасности.

## Безопасность и приватность

Результаты не отправляются на сервер. Нет аналитики, рекламы, сторонних библиотек, запланированных заданий, установки автозапуска, повышения прав без запроса. Файлы старше 48 часов в разрешённой temp-папке могут удаляться **только после ручного согласия**; используемые файлы пропускаются. Удаление невозможно отменить. Перед обслуживанием важных машин сохраните резервную копию данных.

Отчёты сохраняются в `%LOCALAPPDATA%\TurboOldPC\Reports`, служебные результаты фоновых операций — в `%LOCALAPPDATA%\TurboOldPC\Jobs`.

## Структура

- `Start.cmd` — запуск.
- `app/TurboOldPC.ps1` — графическое окно WPF.
- `app/Turbo.Core.psm1` — сбор информации и безопасная очистка.
- `app/Workers/*.ps1` — фоновые операции.
- `tests/SmokeTest.ps1` — проверки без изменения системы.

## Проверка перед публикацией

Открыть PowerShell и выполнить `powershell.exe -NoProfile -File .\tests\SmokeTest.ps1`. Затем вручную испытать интерфейс и действия на Windows 10/11, HDD/SSD, без прав администратора, с отключённым Defender и без интернета. У проекта нет CI/Actions.
